## Culling — Grid and Loupe

These rating and flag keys work on the focused photo (or the whole selection) in both the grid and the full-screen Loupe.

| Key | Action |
|-----|--------|
| 1–5 | Set a 1- to 5-star rating |
| 6 | Clear the star rating (back to 0) |
| P | Pick |
| X | Reject |
| U | Remove flag |
| F | Toggle Reject (Lightroom-style) |
| S | Toggle Pick |

*With* **Rate & advance** *on (Settings → General), rating or flagging a single photo also jumps focus to the next one.*

## Grid navigation

| Key | Action |
|-----|--------|
| ← / → | Previous / next photo |
| ↑ / ↓ | Up / down a row |
| Return | Open the focused photo (Develop; video opens in the Loupe) |
| I | Toggle the info overlay |
| C | Compare (pin + candidate) |
| N | Survey the selection |
| V | Compare versions of this photo |
| ⌥F | Reopen the filter ribbon |
| ⌥S | Show / hide the stack settings |
| Esc | Clear the selection |

*C, N, V, ⌥F and ⌥S are rebindable in* **Settings → Shortcuts**.

## Grid Loupe (hover magnifier)

| Key | Action | Rebind |
|-----|--------|:---:|
| ` | Summon / dismiss the Grid Loupe | ● |
| e | Toggle focus peaking — also in the Lightbox, Compare, Survey and Develop | ● |
| ⇧E | Show / hide where the camera focused — also in the Lightbox, Compare, Survey and Develop | ● |

*The Loupe follows your cursor over the thumbnails — no need to open an image. You can also toggle it with the* **Loupe** *button in the grid toolbar.*

## Loupe (full-screen viewer)

| Key | Action |
|-----|--------|
| ← / → | Previous / next photo |
| Z or Space | Fit to screen (reset zoom) |
| I | Toggle the info panel |
| ⌥T | Fold the filmstrip away / bring it back |
| ⌦ / ⌫ | Move to Trash |
| Esc | Back to the grid |

*Scroll to zoom in and out; drag to pan when zoomed. The rating and flag keys above work here too.*

## Geo Tag

In the Geo Tag view, copy and paste move coordinates instead of text:

| Key | Action |
|-----|--------|
| ⌘C | Copy GPS from the focused photo |
| ⌘V | Paste GPS onto the active/selected photos |

*In the Grid and Develop views the same keys drive Lift & Stamp instead: ⌘C copies the focused photo's look (the Copy Settings dialog appears the first time in a folder; ⌘⇧C brings it back), ⌘V stamps it onto the target photos.*
